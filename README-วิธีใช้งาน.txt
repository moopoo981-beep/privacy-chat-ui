Privacy Chat UI - Step 6.2 Room Code + Typing Beep

สิ่งที่เพิ่ม:
- ต้องใส่รหัสห้อง E2EE ก่อน ถึงจะโหลด/อ่านข้อความในห้องได้
- คนที่มีแค่ Room ID จะยังไม่เห็นข้อความ ต้องมีรหัสห้องด้วย
- ข้อความถูกเข้ารหัสในเบราว์เซอร์ก่อนส่งเข้า Supabase
- ตอนพิมพ์ข้อความมีเสียงตี๊ด ๆ ด้วย Web Audio API
- Supabase เก็บเฉพาะ ciphertext + iv ไม่เก็บข้อความจริง

วิธีใช้:
1. เปิด app.js
2. ใส่ SUPABASE_URL และ SUPABASE_ANON_KEY ของคุณ
3. เปิด index.html
4. Login / สมัครสมาชิก
5. สร้างห้องหรือเข้าห้อง
6. ใส่รหัสห้อง E2EE อย่างน้อย 8 ตัว แล้วกด “ใช้รหัส”
7. ส่งข้อความ

หมายเหตุ:
- รหัสห้องไม่ถูกส่งขึ้น Supabase ต้องบอกสมาชิกผ่านช่องทางอื่น
- ถ้าใส่รหัสผิด จะอ่านข้อความไม่ได้
- เสียงพิมพ์จะทำงานหลังผู้ใช้เริ่มพิมพ์ เพราะเบราว์เซอร์บล็อกเสียงอัตโนมัติจนกว่าจะมี user gesture
